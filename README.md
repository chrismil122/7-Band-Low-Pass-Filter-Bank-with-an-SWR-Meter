# 7-Band Low-Pass Filter Bank with an SWR Meter
I am building a low pass filter bank for 40M-10M with an SWR Meter for a 3-part radio project. This component will filter any receive signal so that it only listens to the Amateur Radio bands and will also filter any transmit harmonics so to be compliant with FCC Part 97 Regulations. Also, I do not look forward to burning out any final transistors so I will also add an SWR Meter to either lower the transmit power or just simply cease transmission (probably will restrict transmission if it's like 5:1 or worse). Lastly, this is meant to be modular so I will interface via SMA for the RF and I2C for toggling the relays to the filters and possibly an ADC for the SWR Meter.
